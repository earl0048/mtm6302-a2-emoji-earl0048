## About
This project is a responsive emoji gallery made with HTML, CSS, and JavaScript.

The gallery displays emojis along with their decimal Unicode codes.

## Features
- Displays 12 different emojis.
- Creates emoji cards using JavaScript.
- Uses a function to control how many emojis are displayed.
- Uses CSS Grid to make the gallery responsive.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open `index.html` in your browser to view the gallery.
2. Open the browser console to change how many emojis appear.
3. Use `showEmojis(4)` to display the first four emojis.
4. Use `showEmojis()` to display all emojis again.

## Files
- `index.html`- Page structure
- `style.css` - Page styling
- `script.js` - Emoji array and gallery function
